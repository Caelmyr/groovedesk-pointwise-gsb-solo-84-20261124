# GrooveDesk 盘面巡检

GrooveDesk 用唱片盘面的俯拍照片记录擦伤、颗粒和磕口，帮助检查盘照光线、盘缘和径向纹理。练习唱片是可重现的合成图。平台只处理盘面图像。

运行 `./start.sh` 后打开 [本地巡检台](http://127.0.0.1:19887/)。通过 `GROOVEDESK_PORT` 更改端口。`./start.sh stop` 删除服务容器，保留命名数据卷。

- 导入已尽量拍正的 PNG、TIFF 或 JPEG，或载入练习唱片。可在照片准备页编辑照片后送回巡检台。
- 在原片上点选盘心、内圈、外圈和零位。输入外圈实测直径后可保存标定。半径字段以原片短边为单位，盘面角度从零位顺时针计。
- 生成展开时最外圈在上，鼠标点在展开图上会定位到原片。对局部范围可打开角度切片。
- 分带线核对：在展开图拾取一段沟纹后，系统在相隔 45° 的八个方向扫描径向亮峰，按半径聚类并核对是否为同一圆周。仅在一两个相邻方向出现的亮弧视为反光窄线；支持方向达到四个且角覆盖足够的候选才判定为完整分带线。窄线与覆盖更完整的旁线冲突时，默认采用旁线；某侧没有合格候选时标明缺边并沿用原环区内圈或外圈。采用默认边界对后，角度切片与展开点回原片都限定在两圈之间，外圈实测直径与原环区标定保持不变。
- 表面标记支持用展开图两个点框出角度与半径范围。点击标记行可以定位，对当前草稿可撤销单条标记。随标定保存可继续编辑。
- 照明巡检给出十二个扇区的入画和光度。盘缘读数在设定外圈附近寻找由暗转亮的边缘。径向纹理用相邻半径的亮度变化指示纹理分布。
- 保存本次检查可重开相同坐标与读数。可下载 CSV、原片标注 PNG 和展开 PNG。

单图上限 22 MB、1400 万像素，每边至少 32 像素。16 位灰度用于分析，PNG 展开预览用 8 位显示。盘面模型假定盘照近似正拍，像素半径与毫米换算用用户设定的实测直径。盘缘读数需要足够的盘缘/背景对比，裁切、透视和反光会影响报告。

容器使用锁定的 Python 3.12 依赖，兼容已锁定的 Python 3.11。后台源码可使用 `python3 scripts/count_backend.py --project-root . --source-root groovedesk --source-root image_lab --output backend-count.json` 复算。
